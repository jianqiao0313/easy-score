# 高、中优先级优化

前置提交：`82dcfee`，默认钢琴及萨克斯采样调整。用户已授权继续完成音色检查报告中的全部高、中优先级事项。

## 清理计划

保持上传格式、50 MB 限制、历史乐谱、固定行宽与自动排版、播放器行为。先补充缺失的失败路径与异步回归测试，再按模块改动；不新增依赖。

1. 服务端队列：隔离每个任务的读写失败，外层 finally 释放执行状态；失败不无限重试，后续任务继续。回归覆盖开始/结束落盘失败、下一任务、进度保存。
2. 上传：流式写入临时文件，并限制同时接收/校验的上传数量；验证后移动源文件，避免分块数组加 Buffer.concat。保留现有格式与大小校验，覆盖并发、超限、客户端中断及临时文件清理。XML/MXL 校验仍需有界内存。
3. 导入模块：统一上传、历史加载、轮询及 MusicXML 获取；新请求通过 AbortController 取消旧请求和等待，旧结果不覆盖当前界面。回归覆盖等待中取消、在途取消和快速切换。
4. 排版模块：延迟加载 OSMD；使用可测量的临时容器完成加载、渲染和光标初始化，成功后替换当前谱面。异常/过期操作清理临时实例，旧谱面保持可见和可播放。布局选项失败时回退已保存的实际布局。
5. 入口瘦身：提取排版、导入生命周期及播放控件，入口保留协调职责。保留原有事件与音色提示。

## 验证与独立复查

- 现有基线 63 项测试；新回归需先运行并确认覆盖目标行为。
- 完整 node:test、生产构建、Node 语法检查、git diff --check；项目未配置独立 lint/typecheck。
- 浏览器核实空页面不加载 OSMD、首次导入和历史切换、自动/固定排版、强制排版失败保留原谱、播放/定位和默认钢琴。
- 比较主入口构建体积与原先 1,449.86 kB / gzip 391.30 kB；检查上传资源限制与失败清理。
- 作者与独立审阅者分开检查；审阅提出的问题修正后再验证。

## 决策

采用原有原生 JS + Node 模块边界，不引入框架或状态管理库。上传选择临时文件与有限并发，减少请求阶段的内存复制；仅限制并发的改动更小，但单文件仍保留双份大缓冲，因此同时流式接收。渲染选择完整准备后替换，代价是重排期间短暂保留两份谱面，换取明确的失败恢复边界。

## 实施结果

- 五项高、中优先级问题均已完成。服务端保留原格式及 50 MB 边界；前端拆分为 `score-importer.mjs`、`score-renderer.mjs`、`playback-controls.mjs`，入口负责协调。
- 队列：任务读取、开始保存和结束保存失败不会锁住队列；状态始终释放，进度保存串行，失败状态尽力保存一次，后续任务继续。任务创建失败删除部分目录。
- 上传：接收阶段按块写入同盘临时文件，验证后移动原文件；同一进程最多同时接收/校验两个文件，超过时返回 503 和 `Retry-After: 1`。无效、超限、中断及创建失败均清理临时文件。chunked 超限会排空请求后返回 413，保留可读取的错误响应。XML/MXL 与图片原有校验继续使用一个至多 50 MB 的源文件缓冲；MXL 解压仍受原有界限约束。
- 请求取消：新导入或历史加载会中止旧 fetch、XML body 读取和轮询等待；过期结果不再触发当前 UI 更新。浏览器测试发现原生 fetch 的 this 绑定问题，已修复并补充回归。
- 排版：新实例的加载、两次固定宽度渲染和光标初始化完成后才替换原 DOM。失败保留原谱和播放器；选项回退到实际布局。异步加载完成后再次测量窗口宽度，新导入成功后保存实际布局，覆盖独立复查发现的两个竞争条件。

### 上传内存对比

同一台 macOS、Node 24.18.0，以 `82dcfee` 的旧应用与新应用分别启动独立服务进程，两个客户端同时发送两个恰好 50 MiB 的 PDF 格式测试文件。2 ms 间隔采样服务进程；使用相同的轻量测试识谱引擎，不把 OMR 内存算入上传对比。

| 指标 | 优化前 | 优化后 |
| --- | ---: | ---: |
| 起始 RSS | 63.3 MiB | 62.9 MiB |
| 峰值 RSS | 269.1 MiB | 232.0 MiB |
| 峰值 ArrayBuffer（含 Buffer） | 200.3 MiB | 100.4 MiB |
| 两个请求完成时间 | 64 ms | 73 ms |

这是一次本机热缓存测量，RSS/耗时会随 GC 和磁盘变化；可确认的是接收阶段不再累计整份分块数组，验证使用单份源文件缓冲，同时接收数量有上限。代价是额外临时文件 I/O。基准脚本与测试数据保存在忽略目录 `.local/optimization-review/`，未进入生产构建。
