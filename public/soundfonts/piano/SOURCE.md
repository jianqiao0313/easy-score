The 30 MP3 files in this directory were copied byte-for-byte from the pinned
Tonejs/audio commit. Easy Score made no changes to these files. The distributed
files are 44.1 kHz stereo MP3 derivatives of the original Salamander Grand
Piano sample library. File integrity is recorded in `SHA256SUMS`.

Attribution: "Salamander Grand Piano V3" by Alexander Holm, licensed under
CC BY 3.0 and redistributed from the Tonejs/audio project.

The sample roots cover A0 through C8. The D-sharp and F-sharp filenames map to
the enharmonic flat names used by Easy Score:

- `Ds1`–`Ds7` map to `Eb1`–`Eb7` (MIDI 27, 39, 51, 63, 75, 87, 99).
- `Fs1`–`Fs7` map to `Gb1`–`Gb7` (MIDI 30, 42, 54, 66, 78, 90, 102).
- `A0`–`A7` map to MIDI 21, 33, 45, 57, 69, 81, 93, 105.
- `C1`–`C8` map to MIDI 24, 36, 48, 60, 72, 84, 96, 108.
